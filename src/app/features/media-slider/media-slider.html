Media Slider

Native horizontal scrolling with mandatory snap positions, smooth controls, and optional captions.

Aspect Ratio and Dimension Reference

Ratios are width:height; dimensions below are example source image sizes in pixels. Display sizes respond to the viewport and the configured slide width.

Media frame sizing at a glance
Format Aspect Ratio Example Dimensions (W × H) Configuration
Standard 4:3 (default) 1200 × 900 px aspectRatio="4 / 3"
Widescreen 16:9 1920 × 1080 px aspectRatio="16 / 9"
Portrait 9:16 1080 × 1920 px aspectRatio="9 / 16"

Frame height = slide width × ratio height ÷ ratio width. Captions sit below the frame and add to the total slide height. Images and videos fill the frame with object-fit: cover, so different source ratios may be cropped. Projected content with a minimum height can make the frame taller than its preferred ratio.
