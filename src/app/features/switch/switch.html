Classic Switches Push critical alerts immediately. Reduce spacing in dense views. Available on enterprise plans. Enabled by your administrator. Review visibility settings before enabling. Places text before the switch.

Slim Track

Set variant="slim-track" for a 24px thumb centered over a 16px track, extending 4px above and below the track. Set variant="classic" for the original style. Omitting variant uses the global default, which is classic unless configured.

Semantic Colors and Global Defaults

Choose success, warning, danger, or info with the kind input. Selected switches use a solid semantic track and a contrasting thumb in both variants. Configure defaults through provideUiLib and override kind or variant on individual switches. These examples inherit success and slim-track defaults. Toggle a switch to compare its states.

For custom palettes, selectedTrackColor and selectedThumbColor still accept CSS colors and theme variables. Explicit color settings take precedence over the semantic palette.
