Highlight

Find literal text without generating HTML, while preserving the source content and casing.

Interactive Highlighting

Matching is case-insensitive and updates when the primitive search value changes.

@for (part of description | highlight: searchText(); track $index) { @if (part.match) { {{ part.text }} } @else { {{ part.text }} } }

Literal Search Text

Regular-expression metacharacters are escaped and matched as ordinary text.

@for (part of literalText | highlight: literalSearch; track $index) { @if (part.match) { {{ part.text }} } @else { {{ part.text }} } }

Safe Rendering

HTML-like input is interpolated as inert text. The pipe returns data and never creates trusted HTML.

@for (part of htmlLikeText | highlight: htmlLikeSearch; track $index) { @if (part.match) { {{ part.text }} } @else { {{ part.text }} } }
