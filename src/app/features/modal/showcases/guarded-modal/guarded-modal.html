Close Guards and Service State

Dirty state can block synchronous or asynchronous close attempts, including service-level stack operations.

  • canClose allows or rejects synchronous and asynchronous close attempts.
  • hasOpenModals() is a reactive boolean signal for stack state.
  • top() returns the top modal reference or null.
  • closeAll() closes top-down and stops when a guard rejects closing; pass { force: true } to bypass guards explicitly.
  • setCanClose() lets modal content install or replace its close guard.
  • close() resolves with whether the guarded close succeeded.
  • afterClosedWithReason() emits only after an approved close.
